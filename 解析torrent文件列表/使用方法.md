1. 先卸载旧的，安装正确库

```
pip uninstall -y bencode bencode.py
pip install bencodepy
```

2. 替换完整脚本为下面这份（已经改成 bencodepy），保存为 `torrent_list.py`


运行命令不变：

```
python torrent_list.py
```

## 使用方法

1. 把你从下载器导出的 `.torrent` 种子，和脚本放在同一个文件夹。
2. 修改脚本里 `TORRENT_FILE = r"test.torrent"`，把`test.torrent`替换成你的种子文件名，例如`r"movie.torrent"`。
3. 在该文件夹地址栏输入 `cmd` 回车，打开命令窗口，运行：

```
python torrent_list.py
```

4. 运行完成，同目录生成 `file_names.txt`，里面就是磁力 / 种子内部**全部文件完整路径 + 文件名清单**。

> 
> 如果文件名中文出现乱码，脚本已经设置 `errors="replace"`，会自动替换无法解码字符，保证能输出。
